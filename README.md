# ClouD ☁️

ClouD is a production-inspired cloud storage platform designed to provide a modern and intuitive experience for managing files and folders.

The project is currently under active development. The frontend file-management interface is being built first, followed by backend integration with Node.js, Express, PostgreSQL, Prisma, and Cloudinary.

## ✨ Features

### Currently Implemented

- File and folder dashboard
- Grid and list view
- File upload interface
- Create and rename folders
- Move files and folders to trash
- Restore and permanently delete items
- Favorite files and folders
- Recent files page
- My Files page
- Search files and folders
- File preview support
- File download functionality
- File and folder details panels
- File and folder action menus
- Outside-click handling for menus and panels
- Escape-key support for overlays
- Responsive and reusable UI components

### Planned Features

- User authentication and authorization
- PostgreSQL database integration
- Prisma ORM integration
- Cloudinary file storage
- Real folder hierarchy
- File and folder sharing
- Storage usage tracking
- Secure file management
- Backend API integration
